FaceLES for Ubuntu
==================

Preferred: install the .deb (double-click it)
  dist/faceles_1.0.0_amd64.deb

  Ubuntu Software / GDebi will ask to install. After that,
  open FaceLES from the applications menu (search "FaceLES").

Without installing
  ./FaceLES
  or double-click "Run FaceLES.sh"

Keep this whole folder together. The FaceLES file is not enough on its own.

Login (until you change it in settings)
  username: saleet
  password: 123

Then click Register face if you want biometric login.

Your data (logs, enrolled face, camera choice) is stored in:
  ~/.local/share/FaceLES/

The web dashboard is separate (the web/ folder on the office machine).
